# HavenHomes

HavenHomes is a real estate website that helps people find properties for sale and rent.

## Features
- Responsive design
- Search for properties
- Filter properties by category
- Dark mode
- FAQ section
- Contaxt form

## Technologies Used
- React
- Vite
- Tailwind CSS
- JavaScript

## How to Run
1. Clone the repository.
2. Run `npm install`.
3. Run `npm rum dev`.
4. Open the local link in your browser.

## Note
The contact form is for demonstration only. It does not send real messages.
